# STAG 🦌 — بهینه‌ساز پینگ گیم

**STAG** نرم‌افزار ویندوز (Electron) برای پیدا کردن سریع‌ترین DNS گیمینگ **بدون باز کردن بازی** است.

مثل یک کلاینت VPN حرفه‌ای: سرورهای DNS را فعال می‌کنی، دکمه استارت را می‌زنی و STAG همه را
**همزمان و موازی** می‌سنجد — بهترین را خودش انتخاب می‌کند. در بخش بهینه‌سازی، دامنه‌های واقعی
بازی انتخابی مستقیم از سیستم خودت روی هر DNS کوئری گرفته می‌شود، پینگ اندازه‌گیری می‌شود،
مسیرهای اختصاصی (روتینگ گیمینگ) شناسایی می‌شوند و پورت‌های TCP بازی هم چک می‌شوند.

## ✨ امکانات

- **دکمه برق واقعی (وصل/قطع DNS سیستم)** — مثل کلاینت VPN: با یک کلیک DNS انتخابی واقعاً روی ویندوز ست می‌شود (netsh با دسترسی مدیر/UAC) و با خاموش‌کردن، سیستم به حالت خودکار (DHCP) برمی‌گردد؛ کش DNS هم خودکار پاک می‌شود
- **بروزرسانی داخل برنامه (فقط تغییرات)** — از بخش تنظیمات؛ آپدیت فقط بلوک‌های تغییرکرده نصاب را دانلود می‌کند (blockmap دیفرانسیلی)، با نوار پیشرفت و نصب با یک راه‌اندازی مجدد
- **تشخیص وضعیت DNS سیستم** — کارت «وضعیت DNS سیستم» نشان می‌دهد DNS روشن است یا خاموش، روی کدام اینترفیس؛ اگر خودت دستی DNS گذاشته باشی آن را به‌عنوان «DNS دستی» نشان می‌دهد و قابل قطع‌کردن است
- **پینگ واقعی مخصوص بازی انتخابی** — هیچ پینگ الکی وجود ندارد: دامنه واقعی بازی از روی هر DNS کوئری می‌شود و TCP-handshake به سرور بازی روی «پورت‌های واقعی همان بازی» اندازه‌گیری می‌شود؛ چند IP پاسخ‌داده مسابقه می‌دهند و سریع‌ترین دست‌دادن ثبت می‌شود (نه probe عمومی)
- **پایش زنده پینگ و پکت** — هر ۲ ثانیه یک پکت واقعی به سرور بازی؛ نمودار لحظه‌ای پکت‌ها (پکت‌های دورریخته قرمز)، پینگ فعلی/میانگین/جیتر/درصد loss — بعد از وصل شدن DNS، پایش از طریق DNS سیستم ادامه پیدا می‌کند
- **نمایش جفتِ DNS هر سرویس کنار هم** — هر سرویس (مثل شکن یا کلادفلر) با نام و نوع سرویس بالا کارت، و هر دو آی‌پی DNS‌اش کنار هم با پینگ جداگانه تست و نمایش داده می‌شوند
- **تست موازی تا ۱۲ سرویس** — همه سرویس‌های فعال با همه آی‌پی‌هایشان در یک لحظه سنجیده می‌شوند؛ نتیجه‌ها زنده و مرتب‌شده از بهترین
- **تست واقعی DNS** — کوئری UDP 53 مستقیم به DNS خودت با `node:dns` (نه فقط HTTP ping)
- **مقایسه با مرجع** — تشخیص «مسیر اختصاصی» با مقایسه در سطح پیشوند IP، مقاوم در برابر round-robin CDNها
- **۱۸ بازی و پلتفرم** — Marvel Rivals، Valorant، Call of Duty، PUBG، Fortnite، CS2، Dota 2، League of Legends، EA، PSN، Xbox، Nintendo Switch، Steam، Battle.net، Rockstar (GTA)، Roblox، Epic Games و Genshin Impact — با آیکون رسمی هر برند؛ بازی انتخابی همیشه بالای داشبورد دیده می‌شود
- **۱۸ سرویس DNS** — گیمینگ ایران (رادار گیم، وانیلا، الکترو، زئوس، ممو)، رفع تحریم ایران (شکن، بگذر، ۴۰۳، شاتل، پیشگامان، آسیاتک) و جهانی (Cloudflare، Google، Quad9، OpenDNS، AdGuard، Control D، DNS.WATCH، Yandex، Mullvad) + افزودن سرور دلخواه
- **ابزارهای سریع** — «وصل بهترین» بعد از تست، کپی آی‌پی‌ها، پاک‌کردن کش DNS، بررسی اتصال اینترنت
- **تست پورت TCP** — چک کردن پورت‌های واقعی هر بازی (مثل 3074، 443 و...)
- **تم شب و روز** — حالت شب: سیاه + فیروزه‌ای | حالت روز: سفید + فیروزه‌ای (با ذخیره انتخاب)
- **کاملاً آفلاین** — سرور تست داخل خود برنامه است؛ هیچ اطلاعاتی جایی ارسال نمی‌شود
- **فارسی و RTL** — فونت وزیرمتن (باندل‌شده، بدون نیاز به اینترنت)

## 📦 دانلود و نصب ویندوز

آخرین نسخه از صفحه [Releases](https://github.com/pvwvuow/stag/releases/latest):

| فایل | توضیح |
|------|-------|
| `STAG-Setup-1.3.0.exe` | نصاب استاندارد (NSIS) — نصب در Program Files با شورتکات دسکتاپ؛ برای آپدیت خودکار داخل برنامه این نسخه را نصب کن |
| `STAG-Portable-1.3.0.exe` | نسخه پرتابل — بدون نصب، اجرای مستقیم (آپدیت = دانلود نسخه جدید) |

> نصب‌کننده امضای دیجیتال ندارد؛ ممکنه Windows SmartScreen هشدار بده — «More info → Run anyway» را بزن.

## 🛠 بیلد از سورس

پیش‌نیاز: Node.js 18+

```bash
npm install
npm run dist        # نصاب NSIS در پوشه release/
npx electron-builder --win portable   # نسخه پرتابل (جداگانه)
```

اسکریپت‌های دیگر:

```bash
npm run dev           # وب‌اپ توسعه روی localhost:3000
npm run electron:dev  # اجرای Electron روی خروجی dev (hot-reload)
npm run build         # بیلد استاندالون Next.js
npm run icon          # تولید مجدد آیکون‌ها (build/icon.png و icon.ico)
```

> نکته لینوکس/مک: بیلد NSIS روی لینوکس بدون wine با پچ `patches/app-builder-lib+25.1.8.patch`
> کار می‌کند که به‌صورت خودکار توسط `postinstall` اعمال می‌شود.

## 🏗 معماری

```
┌────────────────────────────────────────────────┐
│ Electron Main Process (electron/main.cjs)      │
│  • پنجره فریم‌لس + IPC دکمه‌های پنجره          │
│  • اجرای سرور Next.js استاندالون روی           │
│    127.0.0.1:<پورت آزاد> به‌صورت چایلد پروسس   │
└──────────────┬─────────────────────────────────┘
               │ http://127.0.0.1:<port>
┌──────────────▼─────────────────────────────────┐
│ Renderer (Next.js + React + Tailwind)          │
│  • AppShell با سایدبار و ۵ نما                 │
│  • POST /api/ping  → سنجش پینگ هر DNS (موازی) │
│  • POST /api/dns   → کوئری دامنه + تست TCP    │
│    (node:dns Resolver + node:net Socket)       │
└────────────────────────────────────────────────┘
```

- `electron/main.cjs` — چرخه حیات اپ، پنجره فریم‌لس، اجرای سرور امبد‌شده، IPC، موتور بروزرسانی (electron-updater با دانلود دیفرانسیلی)
- `electron/preload.cjs` — bridge امن (contextIsolation فعال) برای کنترل پنجره + API بروزرسانی
- `src/components/stag-store.tsx` — state مرکزی (سرورها، بازی، تست‌ها) با ذخیره محلی
- `src/components/app-shell.tsx` — اسکلت سایدبار + نماها
- `src/components/views/*` — داشبورد، بهینه‌سازی پینگ، سرورها، تنظیمات، درباره
- `src/lib/dns-catalog.ts` — کاتالوگ ۱۸ سرویس DNS با پرچم و نکته دسترسی
- `src/lib/games.ts` — ۱۸ پریست بازی (دامنه‌ها + پورت‌ها + آیکون برند)
- `src/lib/game-icons.ts` — گلیف‌های رسمی برندها (simple-icons، باندل آفلاین)
- `src/app/api/ping/route.ts` — پینگ گیم‌محور (کوئری دامنه بازی + TCP-handshake به سرور بازی؛ حالت «system» برای پایش از DNS سیستم)
- `src/app/api/system-dns/route.ts` — تشخیص و تغییر واقعی DNS ویندوز (netsh + UAC، برگشت به DHCP، flushdns)
- `src/app/api/dns/route.ts` — موتور تست کامل (دامنه، لایتنسی، مقایسه مرجع، TCP)
- `scripts/afterPack.cjs` — تزریق آیکون و ورژن در exe با resedit (بدون wine)

## ⚠️ محدودیت‌ها

کوئری‌ها از سرورِ داخل برنامه (همون سیستم خودت) ارسال میشن — پس برخلاف نسخه وب،
DNSهای با آی‌پی داخلی ایران هم از این برنامه **قابل تست واقعی** هستن. فقط دقت کن
خود سیستم/روترت به پورت 53 خروجی دسترسی داشته باشه. بعضی سرویس‌ها (مثل شکن و زئوس)
معمولاً فقط به IPهای داخل ایران جواب میدن؛ برنامه برای هر سرویس نکته دسترسی را نشان میدهد.

تغییر DNS سیستم نیازمند دسترسی مدیر است — با اولین «وصل» یا «خاموش»، پنجره UAC ویندوز باز می‌شود و باید تأیید کنی. STAG هیچ VPN یا پروکسی‌ای نیست؛ فقط DNS را عوض و تست می‌کند.
