# STAG 🎮 — تستر DNS گیم

**STAG** نرم‌افزار ویندوز (Electron) برای بررسی سلامت DNSهای گیمینگ **بدون باز کردن بازی** است.

آی‌پی DNSهایی که روی کنسول / PC / روتر ست کردی رو وارد کن (یا از پیشنهادهای آماده انتخاب کن)،
بازیت رو انتخاب کن و تست بگیر — هر DNS مستقیم کوئری میشه، پینگش اندازه گرفته میشه،
آی‌پی‌هایی که برای دامنه‌های بازی برمی‌گردونه با DNSهای مرجع (گوگل/کلادفلر) مقایسه میشه
و پورت‌های TCP خود بازی هم چک میشن.

## ✨ امکانات

- **تست واقعی DNS** — کوئری UDP 53 مستقیم به DNS خودت با `node:dns` (نه فقط HTTP ping)
- **مقایسه با مرجع** — تشخیص «مسیر اختصاصی» (روتینگ گیمینگ) با مقایسه در سطح پیشوند IP، مقاوم در برابر round-robin CDNها
- **تست پورت TCP** — چک کردن پورت‌های واقعی هر بازی (مثل 3074، 443 و...)
- **۱۱ پریست بازی** — PSN، Xbox، Call of Duty، Fortnite، EA، Riot، Steam، Nintendo، Roblox، Rockstar و **Marvel Rivals**
- **پیشنهادهای آماده** — DNSهای گیمینگ ایران (رادار گیم، وانیلا، الکترو، زئوس)، سرویس‌های ایرانی (شکن، بگذر، ۴۰۳، شاتل، پیشگامان) و خارجی (گوگل، کلادفلر، Quad9، ادنا، OpenDNS، Comss)
- **تم شب و روز** — حالت شب: سیاه + فیروزه‌ای | حالت روز: سفید + فیروزه‌ای (با ذخیره انتخاب)
- **رابط نرم‌افزاری** — تایتل‌بار سفارشی، دکمه‌های کمینه/بیشینه/بستن، آیکون اختصاصی، کاملاً آفلاین
- **فارسی و RTL** — فونت وزیرمتن (باندل‌شده داخل برنامه، بدون نیاز به اینترنت)

## 📦 دانلود و نصب ویندوز

فایل‌های آماده در پوشه `release/` (بعد از بیلد):

| فایل | توضیح |
|------|-------|
| `STAG-Setup-1.0.0.exe` | نصاب استاندارد (NSIS) — نصب در Program Files با شورتکات دسکتاپ |
| `STAG-Portable-1.0.0.exe` | نسخه پرتابل — بدون نصب، اجرای مستقیم |

> برنامه کاملاً آفلاین کار می‌کند؛ سرور Next.js داخل خود برنامه اجرا می‌شود.

## 🛠 بیلد از سورس

پیش‌نیاز: Node.js 18+ (روی ویندوز نیازی به wine و ابزار اضافه نیست)

```bash
npm install
npm run dist        # نصاب NSIS + Portable در پوشه release/
```

اسکریپت‌های دیگر:

```bash
npm run dev           # وب‌اپ توسعه روی localhost:3000
npm run electron:dev  # اجرای Electron روی خروجی dev (hot-reload)
npm run build         # بیلد استاندالون Next.js
npm run icon          # تولید مجدد آیکون‌ها (build/icon.png و icon.ico)
```

> نکته لینوکس/مک: بیلد NSIS روی لینوکس بدون wine با پچ `patches/app-builder-lib+25.1.8.patch`
> کار می‌کند که به‌صورت خودکار توسط `postinstall` اعمال می‌شود.

## 🏗 معماری

```
┌────────────────────────────────────────────────┐
│ Electron Main Process (electron/main.cjs)      │
│  • پنجره فریم‌لس + IPC دکمه‌های پنجره          │
│  • اجرای سرور Next.js استاندالون روی           │
│    127.0.0.1:<پورت آزاد> به‌صورت چایلد پروسس   │
└──────────────┬─────────────────────────────────┘
               │ http://127.0.0.1:<port>
┌──────────────▼─────────────────────────────────┐
│ Renderer (Next.js + React + Tailwind)          │
│  • UI فارسی RTL با تم فیروزه‌ای               │
│  • POST /api/dns → کوئری UDP + تست TCP        │
│    (node:dns Resolver + node:net Socket)       │
└────────────────────────────────────────────────┘
```

- `electron/main.cjs` — چرخه حیات اپ، پنجره فریم‌لس، اجرای سرور امبد‌شده، IPC
- `electron/preload.cjs` — bridge امن (contextIsolation فعال) برای کنترل پنجره
- `src/components/titlebar.tsx` — تایتل‌بار سفارشی + سوییچ تم شب/روز
- `src/app/api/dns/route.ts` — موتور تست DNS (کوئری، لایتنسی، مقایسه مرجع، TCP)
- `src/lib/games.ts` — پریست بازی‌ها (دامنه‌ها + پورت‌ها)
- `src/lib/dns-suggestions.ts` — DNSهای پیشنهادی ایران و خارج
- `scripts/afterPack.cjs` — تزریق آیکون و ورژن در exe با resedit (بدون wine)

## ⚠️ محدودیت‌ها

کوئری‌ها از سرورِ داخل برنامه (همون سیستم خودت) ارسال میشن — پس برخلاف نسخه وب،
DNSهای با آی‌پی داخلی ایران هم از این برنامه **قابل تست واقعی** هستن. فقط دقت کن
خود سیستم/روترت به پورت 53 خروجی دسترسی داشته باشه.
